# 졸업요건 플래너

## 무엇을 할 수 있나요?

- **요건별 진행 상황**: 전공, 교양, 2전공, 총 이수학점, 3000단위 이상 학점을 함께 계산합니다.
- **이수 상태 반영**: 이수·수강중·예정 상태를 구분해 현재 충족과 충족예정을 나눠 보여줍니다.
- **중복인정 계산**: 의공학전공과 의료AI반도체융합전공 사이의 중복 과목과 최대 인정 학점을 반영합니다.
- **추가 과목 관리**: 편람에 고정된 과목 외 수강 과목도 직접 추가해 총학점과 단위 요건에 반영할 수 있습니다.
- **상세 근거 확인**: 요건별 판정 결과와 계산에 사용된 과목, 학점을 상세 화면에서 확인할 수 있습니다.
- **개인 데이터 이동**: JSON 백업·복원과 엑셀 내보내기를 지원합니다.

## 개인정보와 저장 방식

이 플래너는 서버 계정이나 로그인을 사용하지 않습니다. 프로필, 과목 이수 상태, 사용자 추가 과목은 사용하는 브라우저 또는 데스크톱 앱의 로컬 저장소에만 보관됩니다.

환경을 옮길 때는 설정 화면에서 JSON 백업을 내보낸 뒤 새 환경에서 복원하세요. 배포용 코드와 설치 파일에는 개인 이수 정보가 포함되지 않습니다.

## 빠른 시작

### 필요 환경

- Node.js 22 이상
- pnpm 11 이상

### 개발 서버 실행

```bash
pnpm install
pnpm dev
```

### 품질 검사

```bash
pnpm test
pnpm lint
npx tsc --noEmit
pnpm build
```

## 데스크톱 앱

Tauri로 같은 화면을 로컬 데스크톱 앱으로 실행할 수 있습니다. 처음 빌드하기 전에는 [Tauri v2 선행 조건](https://v2.tauri.app/start/prerequisites/)에 따라 Rust와 운영체제별 도구를 설치해야 합니다.

```bash
# 데스크톱 앱 개발 모드
pnpm desktop

# 현재 운영체제용 설치 패키지 생성
pnpm desktop:package
```

macOS에서는 `.app`과 `.dmg`, Windows에서는 `.msi` 패키지를 생성합니다.

## 프로젝트 구조

```text
app/          웹 앱 화면과 라우팅
lib/          졸업요건 데이터와 계산 로직
desktop/      Tauri용 React 진입점
src-tauri/    Tauri 네이티브 설정과 Rust 코드
tests/        계산 로직 테스트
```

## 유의 사항

이 도구는 2022학번 의공학전공 및 의료AI반도체융합전공 관련 편람을 바탕으로 만든 개인 확인 도구입니다. 실제 졸업 심사와 적용 기준은 학사 공지, 소속 학부 및 학교의 최종 안내를 우선해 확인해야 합니다.
